# 每日配音计划

腾讯云免费资源包与 TTSMaker 单句导入可作为备用。领取资源包、填写密钥与 A/B 试听的步骤见[免费备用配音与单句试听](免费备用配音.md)。

## 第一次使用

1. 打开 ASGSV，选择鸣潮，完成主页的一键配置。先登录一次要配音的游戏账号，让游戏写入任务进度。
2. 在「任务库 → 每日配音计划 → 配音与预算」选择 BreezeBlue，填写配音 API Key，打开普通支线配音规则，设置每日预算。本计划最多使用每日 400 积分，也遵守你设置的更低上限。
3. 打开「任务库 → 每日配音计划 → 发现支线」。新安装若看到「下载台词索引」，先点击下载。点击「扫描本机未完成支线」，勾选需要的任务，点击「加入每日计划」，也可以点击「一键加入全部」。重复加入同一任务会自动去重。
4. 在「后台时间」选择执行时间，点击「保存时间并启用」。页面会显示 Windows 登记的下次运行时间。「我的计划 → 立即执行」可提前开始本次补录。
5. 完成后，到任务库选择任务和台词，点击「试听当前句」。进入对应的游戏对白后也能从正常的实时配音入口播放。

## 选择自己的游戏角色

账号菜单现在使用游戏内 UID 的尾号。带「最近登录」的是游戏记录中最后登录的角色。旧登录记录尚未和角色对应时，菜单会标为「游戏 UID 待确认」。用自己的账号登录鸣潮、进入大世界，重新打开账号菜单即可核对。后台继续使用手动选定的账号。

如果任务缓存尚未建立，可用已确认属于该角色的游戏日志扫描进行中和可接取的支线。若两处都没有进度记录，进入大世界并打开一次任务列表，再点「扫描本机未完成支线」。要为指定任务提前准备录音，可在任务库取消勾选「扫描到的支线」，按名称选择任务。

## 每日赠送积分

在「每日配音计划 → 每日领积分」点「一键开启每日领取」。已保存的 BreezeBlue 配音密钥会自动复用；首次使用可在本页填入自己的 API Key。尚无密钥时点「获取密钥」直达官方创建页，复制后关闭该专用窗口并粘贴。需要登录时会自动打开专用浏览器，登录同一账号即可，窗口关闭后继续核对到账。默认每天 08:45，可在同一页改时间。完整便携版已包含领取组件，首次启用时会在当前 Windows 用户目录安装。使用增量更新或源码安装的用户可联网自动下载，也可从同版本完整便携包复制 `tools/breezeblue-wheels` 文件夹至工作台同一位置。已配置过的用户会沿用原浏览器和登录；首次开启会优先选用默认的 Chrome 或 Edge，也可使用本机另一款。两者均未安装时，首次打开领取功能会联网下载专用 Chromium。各浏览器分别保存专用登录；如果卸载原浏览器，首次切换时需在新窗口登录。

Windows 在设定时间运行，登录电脑时也会补查。日常浏览器、工作台和 Agent 均可关闭。后台先用配音账号的 API Key 核对当天的赠送流水，已经手动领过也会显示实际金额、入账时间和流水尾号。

如果会员身份保存在平时使用的 Chrome 或 Edge，可点「检测自动领取通道」。ASGSV 临时打开一个官网窗口，在密钥列表核对当前配音密钥的公开标识，再读取这个账号的每日奖励卡。检测成功后，每日计划会记住这个通道。浏览器原本关闭时由工具启动，结束时只关闭为本次任务打开的窗口。

运行时，官网明确标出本账号单一的「+400」奖励和「Discord 成员」，或明确写明本次可领 400，ASGSV 才会执行领取。专用浏览器同时显示 400 和 100 时，工具会检查常用浏览器的会员奖励。两个页面都未明确金额、账号不匹配或网站要求本人验证时，会保留当天机会。

「立即领取 / 核对到账」与 Windows 每日计划共用同一套领取程序。工作台会区分「ASGSV 自动领取」和「已核对已有流水」。前者有本工具的提交、官网回执和配音账号的入账记录。后者只表示这笔积分已经在账上。

领取时间和每日配音预算可分别调整。每位用户使用自己的账号、API Key 和 Windows 登录会话。登录状态、密钥、领取计划和到账记录仅保存在用户本机。

## 如何理解扫描和费用

- **进行中、可接取、玩家已确认未完成**分别表示不同的进度依据。列表仅包含有本机证据、且版本索引覆盖的普通支线。日志轮换或刚切换账号可能导致结果减少，重新登录游戏再扫描即可。
- 「我的计划」按账号保存，扫描不会自动添加任务。当前账号、任务进度或资源版本无法确认时，后台会显示原因。任务中有游戏原声、要求沿用原声或声线存在冲突的台词会保留。
- 今日用量显示本机 BreezeBlue 账本的**预留**，包括实时配音及尚待确认的提交。在其他设备消费的积分以 BreezeBlue 网站为准。每日赠送可在「每日领积分」启用自动领取，也可以在 BreezeBlue 网页手动领取。
- 有效的相同录音会直接复用。任务可随时移出，已生成的音频可以继续使用。云端已提交但结果不明的请求会保留记录，避免重复扣费。
- 可关闭 ASGSV 和 Agent。Windows 关机期间错过的计划会在下次登录后补做，仍按执行日的预算计算。更换便携目录前请停用后台计划，在新位置重新启用。

## 让模型帮助选声

在「角色分析」填写模型服务商的 HTTPS API 基址、模型名称和 API Key，点一次「保存并启用每日选声」。软件会验证密钥和模型，成功后显示「已启用」。已在本机保存过该服务的密钥时，可留空密钥框。默认预填 DeepSeek，也可选其他兼容 Chat Completions 的服务。BreezeBlue 配音密钥和角色分析密钥分别保存在 Windows 凭据管理器。

启用后，定时执行和「立即执行」都会先核对剩余预算、已生成录音与任务进度。对当天能生成的普通 NPC 台词，程序先把角色名、上下文和候选音色发给已配置的模型，再开始合成。新角色按性别、年龄和性格选择云端音色；已有绑定的角色保留音色，新录音可使用模型给出的表达提示。已有录音和可用缓存直接复用。

同一天再次执行时会复用已确定的角色档案。换日后，有新台词要生成的角色会重新分析。「角色分析 → 今日选声」列出音色和表达提示，鼠标停在记录上可查看判断依据。角色原声、待核角色和你单独设置的台词演绎继续按原设置处理。「我的计划」会显示选声进度及跳过原因。如果服务鉴权或网络失败，修正「角色分析」配置后点「立即执行」即可继续。模型调用按所选服务商的规则计费，BreezeBlue 的每日配音预算单独计算。

## 后台没有出声或进度未变

后台负责预生成音频，试听请进入任务库。「我的计划」显示每项任务的就绪句数和暂停原因。「后台时间」读取 Windows 任务计划程序的实际登记状态。余额不足时，可在「每日领积分」核对到账后再执行配音。若提示某个任务的台词指纹未匹配，请先检查程序更新，再检查中文台词索引。其他已匹配任务可继续执行。
