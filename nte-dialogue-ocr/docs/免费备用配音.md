# 免费备用配音与单句试听

BreezeBlue 继续使用角色原来选好的主声线。想比较另一个声线时，在「任务库」选择一条有正文的台词，点击角色名，进入「免费备用源 · 单句对比试听」。A 播放本句已有的主声线，B 使用所选的腾讯云声线。点击 B 只处理这一句。相同文本和腾讯云声线可以从缓存重听。

## 腾讯云免费包与密钥

1. 在语音合成控制台进入「语音合成资源包」，领取与音色同档的免费资源包。鲙娘试音使用「云小璇」（403013，活力女青年），对应「超自然大模型 2.0」免费包，获赠 2 万字符，有效期 3 个月。[语音合成控制台](https://console.cloud.tencent.com/tts) · [领取说明](https://cloud.tencent.com/document/product/1073/56352) · [计费与免费额度](https://cloud.tencent.com/document/product/1073/34112)
2. 在腾讯云语音合成控制台关闭后付费，并核对同档只有免费包。腾讯云会在资源耗尽时停服。如果修改云端计费条件，请先在 ASGSV 停用此源。[官方停服说明](https://cloud.tencent.com/document/product/1073/111771)
3. 在腾讯云访问管理中创建供 ASGSV 使用的 API 密钥。使用子账号时，需要能调用语音合成 TextToVoice。ASGSV 保存前会用 GetCallerIdentity 确认密钥所属主账号。[API 密钥管理](https://console.cloud.tencent.com/cam/capi)
4. 打开「任务库 → 每日配音计划 → 配音与预算 → 免费备用源 · 腾讯云与 TTSMaker」，输入 SecretId 和 SecretKey，选择免费包档位并确认云端计费条件。密钥存入本机 Windows 凭据管理器。
   - 只想听一条时，点击「仅验证密钥，先试听一句」。每个腾讯云账号的每个档位可登记一次单句试音，验证后 30 分钟内可提交，后台任务用不了这项许可。
   - 想供后续配音使用时，填控制台显示的剩余字符和到期日，点「验证身份并保存」。显示的是本机使用上限。多人或其他设备共用腾讯云账号时，以控制台为准，可将本机上限调低。ASGSV 在填写的到期日当天停止新请求。

## 选择与使用备用声线

在单句对比窗口点 B，听到满意的声音后，点「设为该角色的腾讯云备用声线」，才会用于该角色后续缺音频的台词。角色更换主声线时应重新试听对应的备用音色。BreezeBlue 未提交请求（如当日预算不足）或服务明确拒绝时，工具可以使用已确认的备用。若上次提交超时且收费状态不明，会停下来等待核对。

腾讯云只按所选档位使用免费资源。额度在同一 Windows 用户的 ASGSV 实例之间共用，耗尽或到期后仍可播放已经生成的录音。游戏账号沿用原来的 BreezeBlue 每日积分计划。

## TTSMaker 免费网页

在同一个单句对比窗口点击「复制本句并打开 TTSMaker」，粘贴本句、选择中文音色，完成网页验证后下载 WAV。回到 ASGSV，点击「导入 TTSMaker 单句录音」，听完点「采用为本句备用录音」。也可导入 MP3，需要本机可用的 FFmpeg。免费网页通常每周提供 2 万字符，页面标记的部分音色不限量。额度用完时等待官网重置。TTSMaker 的开发者 API 需要收费套餐。[TTSMaker 免费网页](https://ttsmaker.com/zh-cn) · [官方套餐与 API](https://pro.ttsmaker.com/pricing)
