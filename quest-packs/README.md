# 鸣潮任务配音包

共 **17 个完整任务，277 句配音**。每个 ZIP 包含一个任务的中文录音。两列下载链接提供相同的文件，可按任务单独安装。

1. 在下表找到任务，点击「国内下载」或「GitHub 下载」，保留 ZIP 原文件。
2. 使用 **ASGSV v0.4.23 或更高版本**，打开工作台右上角的 **更新 → 导入更新包…**，选中下载的 ZIP。
3. 导入成功后，到 **任务库 → 已配音任务** 搜索任务名，选一句点击 **试听当前句**。播放这些预录音频无需 BreezeBlue 积分。

本批次按鸣潮中文资源 **3.8.13** 核对台词。游戏资源版本和个人角色声线设置会影响游戏内的匹配结果。《它记得》和《失落的味道》也随便携版提供；此目录有适配上述资源版本的独立包。
