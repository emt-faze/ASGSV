# ASGSV 鸣潮支线配音 · v0.4.14

Windows 桌面配音工具。鸣潮模式读取游戏日志，识别对话、停掉上一句并播放当前句。此版本附《失落的味道》168 句和《它记得》13 句中文 AI 配音。《它记得》使用盈叶 B 版，《失落的味道》中的陶老使用已确认的「守艺老匠」。漂泊者使用男声，台词里称呼玩家时使用「漂泊者」。

[下载含程序和两项完整配音的 Windows ZIP](https://github.com/emt-faze/ASGSV/releases/download/wuwa-v0.4.14/ASGSV-v0.4.14-Windows-Quests.zip) · [发布记录与 SHA-256](https://github.com/emt-faze/ASGSV/releases/tag/wuwa-v0.4.14)

1. 安装 64 位 Python 3.12，将 ZIP 完整解压到可写目录。首次联网运行 **安装鸣潮日志配音.bat** 安装依赖。
2. 双击 **ASGSV.exe**。在「设置」中选择鸣潮安装目录（其中应有 Wuthering Waves Game 文件夹），保存。
3. 打开鸣潮，进入上述任务，点击「重新连接 / 刷新音频」或重新打开工具。程序根据日志里的场景与字幕编号播放。F8 暂停，F9 重播，F10 跳过。只播放附带音频无需云端密钥或本地合成模型。
4. 需要为其他普通支线配音时，先在任务库建立中文台词索引，再在设置启用普通支线规则、选择合成方式。BreezeBlue 用户填写自己的密钥和每日预算，并在任务库确认主要人物声线。任务库会根据自称、明确指名和相邻对话给出性别与年龄建议，鼠标停在建议上可看依据。
5. 其他游戏与 OCR 功能沿用 **安装台词生成工具.bat**。[原有功能与安装指南](docs/台词生成工具使用指南.md)

任务包按游戏资源挂载清单匹配，已核对 **3.7.19 和 3.8.9 中文资源**。游戏更新后，清单不符时这些预录不会自动播放。音频位于 `game-data/wuwa/voice-pack/audio`，对应台词见同目录的 `pack.json`。这是非官方玩家 AI 二创配音。游戏、角色与剧情归原权利人所有。第三方代码及模型说明见 [第三方声明](THIRD_PARTY_NOTICES.md)。
