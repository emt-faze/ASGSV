## 快速开始

1. 安装 **Python 3.12（64 位）**，勾选 Add python.exe to PATH。
2. 完整解压下载包，双击 **安装台词生成工具.bat**。
3. 双击 **打开台词生成工具.bat**。系统中文声模式可先进行手动添加、批量生成和试听。
4. 需要角色声音时，运行 **安装角色配音模型.bat**，然后在工具内 **添加角色声线…**。首次导入后，关闭工具并运行 **设置默认角色声线.bat**，再重新打开并选择角色模式。
5. 点击 **识别游戏台词…**，选择游戏窗口并框选正文与角色名区域；核对台词后生成音频。
6. 点击 **自动识别并播放…**。当前项目中已生成且有效的音频会随游戏字幕播放，切句后停止旧音频。
7. 保存文字或分享配音时，点击 **导出台词…**，选择范围、格式和保存位置。

首次使用需校准游戏区域。系统模式要求 Windows 有中文朗读声音；角色模型要求支持 CUDA 的 NVIDIA 显卡和驱动，建议完整安装预留至少 15 GB 空间。自动播放已准备好的音频不需要加载 TTS 模型。

## v0.4.12 新增与改进

- **深色主题显示修复**：窗口、按钮、表头、输入框、选中和禁用状态采用一致的浅色配色，避免白字落在浅色背景上；子窗口和运行中切换主题也纳入检查。
- **按钮悬停说明**：鼠标停留片刻即可查看作用、处理范围和使用条件；覆盖声线、视频、导出与识别播放等窗口，暂停/继续、试听/停止的提示随状态更新。
- **保留数据的升级补丁**：已装 v0.4.11 的用户可下载小补丁，无需重新安装模型；关闭工具后把 `ui-update` 放进 `nte-dialogue-ocr`，双击其中的 `双击更新界面.bat`。补丁先备份，遇到不同版本或已修改的文件会停止。

“当前行”是高亮的一行，“勾选项”是左侧打勾的条目。另一台电脑若显示“共 0 条”，需要打开或导入项目；仅更新程序不会同步个人台词和声线。窗口标题栏仍可能随系统设置而异。

## v0.4.11 已有功能

- **台词导出**：主窗口“导出台词…”支持全部台词或左侧勾选项；导出 TXT、CSV，或包含已有有效 WAV 的 ZIP。保留顺序、角色名、换行和核对状态，缺少音频也保留文字。
- **批量建立声线**：扫描角色素材目录、推荐参考片段、可选离线转写、保存可恢复草稿；试听并逐字核对后才加入声线库，同名角色不会覆盖。
- **视频添加声线**：可选长录屏中的 3–30 秒范围，也可扫描短视频；原视频保留，角色由使用者明确指定。
- **声线核对与播放统计**：集中核对勾选项，显示角色名/别名/手动指定等匹配来源，并记录自动播放各阶段耗时。
- **音频首尾整理**：结合语音位置与持续音量整理过长空白，保留句中停顿与起音尾音；不改变音量或播放速度。
- **生成失败恢复**：仅在音频未自然结束时更换随机种子并增加长度再试一次，两次尝试共用 150 秒生成上限；残缺音频不记作成功。

自动转写是可选组件：先安装主程序，再运行根目录 **安装声线自动转写.bat**，首次下载组件和约 486 MB 模型，之后使用 CPU 离线转写。未安装时可试听后手动填写参考台词。下载包不含此转写模型。

v0.4.12 公开源码检查：**500 项通过，28 项因未公开私人取样而跳过**。原有 `tools/voice-library` 参考模块保留，集成到窗口的实现位于 `nte-dialogue-ocr/voice_library.py`。详见[验证记录](docs/台词生成工具验证记录.md)。

## 原有功能

- OCR 采集与旧记录导入，手动添加、编辑、删除和撤销删除台词。
- 导入音频或录屏中的角色参考片段，支持角色名、别名和系统声线配置。
- 批量生成、整句缓存、自然分段、停止、失败重试和逐句试听。
- 自动识别字幕并播放当前项目的完整音频，支持切句中断、暂停、跳过与重播。
- 主窗口与采集/播放窗口联动最小化，后台工作继续。
- 修复参考片段末尾残音混入新配音开头、标点前发音截断，以及背景文字和继续图标造成的误判。
- 修复明音凛长句在背景切换后从“已复核”变成“待复核”并停止播放的问题。

自动播放只使用提前完成的项目音频；未生成、缺字或无法明确匹配时会提示。游戏已有原配音时可手动暂停。不同机器、游戏设置与字幕布局仍需自行校准，模型新台词的生成速度与硬件有关。
