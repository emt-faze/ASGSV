# 社区配音

在开发版打开 **任务库 → 社区配音**。选择任务或搜索投稿作者，点 **试听同一句** 可比较不同版本。点 **下载并启用** 后，任务库与游戏对白使用所选版本。点 **恢复原配音** 可切回原先的本机或官方录音。下载和试听均可匿名使用，无需 BreezeBlue API Key。

## 投稿和举报

1. 在任务库选中自己配齐的支线，打开 **社区配音**，点 **登录 CNB**。首次会下载并校验 CNB 官方登录组件，再由默认浏览器完成授权。
2. 点 **分享我的配音**，核对任务和公开署名。工作台逐句核对本机生成记录、字幕指纹、角色、通用昵称「漂泊者」与 WAV。若遇到读入私人昵称的录音，按提示补录对应句子。
3. 投稿进入私密 Issue。维护仓库的 CNB 定时构建每 15 分钟检查一次，检查通过后写入公开目录。点 **我的投稿状态** 可看到最近一次投稿的编号、通过结果或具体原因。每个通过检查的投稿都有单独的版本号。自动检查覆盖文件及台词匹配，游戏内效果需另做实机验证。
4. 发现串音、读错称呼等问题，选中具体版本，点 **举报此版**，写明角色和台词。维护者可单独下架该版。

投稿包只包含索引匹配所需的游戏字段、所选任务的 PCM 录音和投稿签名。CNB 署名取自平台账号。游戏 UID、配置、账本、模型服务密钥和本机文件路径保存在本机。

## 维护者上线与验收

在项目的 Python 3.12 环境使用下列命令。默认分支保留校验代码和游戏台词指纹，独立分支 **community-packs** 保存公开目录，Git LFS 保存 ZIP 和试听片段。将分支写权限授予维护者及受信任的构建身份。定时任务从默认分支执行，使用 CNB 为当前仓库签发的临时凭据。

1. 使用非仓库成员账号做线上验收。将账号资料只读和 Issue 读写令牌存入本机环境变量 **ASGSV_CNB_TEST_AUTHOR_TOKEN**。用于独立核对仓库及继承角色的维护者令牌放在 **CNB_TOKEN**，此步骤需要 **repo-manage:r**。运行下面的命令会创建一个私密验收单，上传两片随机数据，核对作者、可见性和读回摘要，然后关闭。验收单与真实配音目录独立。

   `python community/verify_author.py --submit-private-check`

2. 普通账号验收通过后，使用具有代码写入权限的维护者身份执行 **init**，将此版本的构建配置部署到 CNB 默认分支，并启用仓库的定时构建。首次内容分支使用该仓库的 Git LFS 和构建配额。

   `python community/publish.py init`

3. 作者从工作台提交自己生成的完整任务后，用另一台未登录 CNB 的工作台试听、下载、启用和恢复，检查签名、任务版本及公开目录。已发布投稿的检查结果写回投稿人的私密 Issue。
4. 核查举报后，维护者可按投稿编号定向下架。该操作移除目录入口和对应当前分支文件，并登记撤回记录，阻止相同录音再次自动上架。已下载到玩家本机的文件保留。

   `python community/publish.py withdraw --issue 123`

CI 依据平台返回的作者身份校验投稿签名，逐句重算游戏的台词指纹，核对录音哈希、PCM 内容和整任务覆盖。没有内容变更的重复投稿会返回原版本号。客户端通过 CNB 的 HTTPS 公开目录取得预期作者公钥、包摘要与兼容资源记录，再验证签名和音频内容。此信任范围仅涵盖玩家配音。
