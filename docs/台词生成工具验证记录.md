## 可移植处理与分发范围

公共版使用解压目录内的共享配置与模型路径，配置缺失时读取样例，不读取开发电脑的桌面设置。可选转写安装入口先准备组件和加载模型，成功后才写相对路径配置；已有配置保留。转写仍由独立 CPU 进程离线执行。

源码和两个发布包均包含约 1.25 MB 的 Silero VAD 小模型及 MIT 许可，用于配音首尾整理。推荐包另含四个固定版本 OCR 模型。两个包都不含 Python 环境、Qwen3-TTS 权重、约 486 MB 的可选转写权重、私人声线、录屏、台词项目和生成音频。

原始 `tools/voice-library` 参考模块与历史发布保留。新版本没有重新进行完整游戏剧情验收，也不以自动化检查代替人工听感判断。[v0.4.3 的历史验收记录](台词生成工具v0.4.3验证记录.md)仅对应当时版本和使用环境。
