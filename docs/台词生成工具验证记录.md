## 分发范围与验证边界

公开版沿用 v0.4.11 的相对配置和模型路径，不读取开发电脑的桌面设置。可选离线转写的安装方式、已有配置保留规则和模型版本不变。原始 `tools/voice-library` 参考模块与历史发布保留。

源码包和完整包都包含约 1.25 MB 的 Silero VAD 小模型及 MIT 许可；完整包另含四个固定版本 OCR 模型。两个包均不含 Python 环境、Qwen3-TTS 权重、可选转写权重、私人声线、录屏、台词项目或生成音频。界面小补丁仅供已有 v0.4.11 使用。

本次在本机模拟深色主题并验证原生窗口，没有在截图中的另一台实体电脑上测试；标题栏可能随系统设置而异。界面检查不代表新一轮游戏剧情稳定性、模型生成质量或人工听感验收。
