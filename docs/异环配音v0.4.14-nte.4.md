# 异环配音 v0.4.14-nte.4

本版把异环实时配音、游戏台词提取和台词整理放在同一个工作台中。“实时配音”页连接游戏，“任务库与配音准备”页检索原文、整理清单和生成配音项目。

## 安装和首次使用

1. 准备 Windows 10/11、64 位 Python 3.12 和完整安装的《异环》。
2. 在本版 Releases 下载 `dialogue-generator-v0.4.14-nte.4-windows-with-ocr-models.zip`，完整解压到可写目录。
3. 首次联网运行根目录的“安装异环配音.bat”，等待依赖安装与组件校验完成。
4. 双击“打开异环配音.bat”。进入“任务库与配音准备”，程序会自动查找已安装的游戏并检查中文资源版本。首次使用时提取中文台词，进度显示在页面底部。
5. 如果自动查找未找到游戏，点击“选择目录”选择包含 `Client` 的安装目录。也可以选择 `Client` 子目录或游戏程序所在目录，程序会向上查找安装根目录。
6. 在游戏中打开一页完整对话，点击“字幕校准”，按窗口提示标记角色名和台词区域。返回工作台后点击“连接异环”。

完整包包含四个字幕识别模型、NTE 资源读取组件和独立 .NET 运行时。Python 及应用依赖通过安装脚本准备。第一次使用系统中文声音时，Windows 需要已安装可用的中文语音。

源码包使用相同安装入口。安装器按随源码保存的清单下载资源读取组件并校验文件，字幕模型按固定清单下载。

## 自动查找目录和提取台词

程序先检查已保存的有效目录，再从正在运行的游戏或启动器、Windows 安装记录、游戏快捷方式和常用游戏目录查找完整客户端。找到多份安装时会提示选择。

每次启动工具后，首次进入准备页会检查游戏资源。缺少台词库或资源版本发生变化时，程序重新提取中文文本并建立编号、角色和原文索引。“自动识别并提取”按钮可用于手动重新读取。

提取操作可在游戏关闭时运行。手动提取时若实时配音正在运行，工作台先停止配音再更新台词库。完成后点击“连接异环”继续。

## 台词整理与项目

- 在“原文库与日志”中按角色、资源分组、台词文字或编号检索。
- 选择需要的条目后加入“整理清单”，编辑角色、正文和备注。
- 勾选条目后导出 CSV、TXT、JSON，或建立现有格式的配音项目。
- 点击“生成与试听”生成项目录音。实时配音优先复用已选项目中匹配的有效音频。
- “读取本机历史日志”解析已经保存的日志，按编号关联游戏原文。找不到唯一原文的编号保留为待定位。

中文资源总数与“对话相关资源”数量分别显示。对话范围按资源分组识别。角色名缺失、变量待填写和原声状态待确认的条目会在页面中标记，建立项目后可继续核对。

## 实时配音

有可用日志编号时按编号定位原文。部分无配音 NPC 对话只写通用事件，程序通过当前字幕定位原文，翻页后取消上一句的合成或播放。识别模型在会话内保留，非对话阶段降低识别频率。

工作台提供暂停、继续、重播和跳过按钮。已出现原声日志记录的台词会抑制重复补配音。系统中文声音为默认合成方式，角色模型与参考声线可通过原有项目设置使用。

## 从旧版升级

关闭工具，将压缩包内的程序文件合并到现有 ASGSV 安装目录，然后运行“安装异环配音.bat”。安装器会读取已有配置，新增资源读取组件。项目、声音配置和缓存继续从原有目录读取。

已合并的台词整理使用配音工作台的公共台词库。首次升级后进入准备页，完成一次目录与资源版本检查。

## 本机验证范围

已在本机安装的《异环》上验证目录自动识别、中文资源提取和工作台检索。该版本的现场对话核对使用丽妮丝的无配音 NPC 台词，用户确认听到配音且翻页中断正常。

已从完整包解压出的新目录，使用通用默认设置验证首次启动、台词提取、整理清单、项目交接与系统语音 WAV 生成。该次检查复用本机已安装的 Python 依赖。自动回归共 261 项，其中 257 项通过，4 项因系统快捷键、可选鸣潮读取组件或 FFmpeg 不可用而跳过，另有 11 项安装与打包检查通过。

上述结果来自本机 Windows 环境，其他电脑的游戏版本、字幕布局和中文语音需要在首次使用时核对。
